# WebCraft — лендинг

Статична сторінка-візитка студії WebCraft (сайти й онлайн-запис для малого бізнесу).
Одна ціль — увести людину в Telegram (`https://t.me/massiveboy?start=site`).

Чистий HTML/CSS/JS, без фреймворків і збірок. Єдиний «живий» елемент — скролл-демо
сайту салону в рамці браузера (послідовність кадрів, прив'язана до скролу).

## Структура

```
index.html   розмітка (6 блоків)
styles.css   стилі
app.js       скролл-скраб (desktop) + автопрогравання (mobile)
frames/      8 кадрів WebP q70 (900×562)
assets/      обкладинки робіт + og-cover.jpg
fonts/       Unbounded 600 + Golos Text 400 (woff2, cyrillic+latin)
```

## Відкрити локально

```bash
python3 -m http.server 8000
# відкрити http://localhost:8000
```

## Деплой

**Vercel** — просто імпортувати папку як статичний проєкт, нічого налаштовувати.
**GitHub Pages** — запушити вміст папки в репозиторій і увімкнути Pages (корінь).

## Що замінити перед публікацією

1. Домен у `<link rel="canonical">`, `og:url` та `og:image` (зараз `webcraft.example.com`).
2. Переконатися, що фраза «Відповідаю протягом години» — правда.
3. Instagram-нік `xal1f4t` ще читається як старий бренд — за бажанням змінити.
